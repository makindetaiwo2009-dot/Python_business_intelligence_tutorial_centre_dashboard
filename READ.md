# Tutorial Centre Business Intelligence Dashboard

## Overview
This project is an interactive Business Intelligence Dashboard developed using Python and Streamlit.

The dashboard analyzes:
- student demographics
- payment performance
- revenue generation
- BMI categories
- school type distribution
- parent occupation patterns

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- JupyterLab

## Features
- KPI Cards
- Revenue Analysis
- Payment Analysis
- BMI Analytics
- Interactive Filters
- Business Insights Dashboard

## Project Type
Real-world primary data analytics project.
